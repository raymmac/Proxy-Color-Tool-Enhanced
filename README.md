# Proxy Color Tool Enhanced

[🇷🇺 Русская версия](README_RU.md)

> Extended, improved, and optimized version of [Proxy Color Tool](https://steamcommunity.com/workshop/filedetails/?id=2063690158) by [NotAKid](https://steamcommunity.com/id/NotTheKidYouAreLookingFor).

This Garry's Mod tool allows you to paint individual parts or textures on supported models.

> **Important:** This addon only works with models that support proxy colors.

## For Developers

If you want to add proxy-color support to your models, see the original [Proxy Color Tool wiki](https://github.com/NotAKidoS/Proxy-Color-Tool/wiki/Sample-Proxies).

The original system supports 7 slots. **This enhanced version supports up to 10 slots.**

## Features

### 10 Color Slots

Add and customize **10 color slots instead of 7**, giving you more control over model customization.

### Real-Time Preview

Colors are applied to the model in real time while you select or modify them, so you can immediately see the result.

### Multiplayer Synchronization

Real-time color changes are synchronized in multiplayer. Other players can see your changes, and you can see theirs.
