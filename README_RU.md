# Proxy Color Tool Enhanced

[🇬🇧 English version](README.md)

> Расширенная, улучшенная и оптимизированная версия [Proxy Color Tool](https://steamcommunity.com/workshop/filedetails/?id=2063690158) от автора [NotAKid](https://steamcommunity.com/id/NotTheKidYouAreLookingFor).

Этот инструмент для Garry's Mod позволяет раскрашивать отдельные детали или текстуры на поддерживаемых моделях.

> **Важно:** Этот аддон работает только с моделями, которые поддерживают proxy colors.

## Для разработчиков

Если вы хотите добавить поддержку proxy colors для своих моделей, ознакомьтесь с оригинальной [документацией Proxy Color Tool](https://github.com/NotAKidoS/Proxy-Color-Tool/wiki/Sample-Proxies).

Оригинальная система поддерживает 7 слотов. **Эта улучшенная версия поддерживает до 10 слотов.**

## Возможности

### 10 слотов для цветов

Добавляйте и настраивайте **10 слотов вместо 7**, получая больше возможностей для кастомизации моделей.

### Отображение в реальном времени

Цвета применяются к модели в реальном времени во время их выбора или изменения, поэтому вы сразу можете увидеть результат.

### Синхронизация в мультиплеере

Изменения цветов в реальном времени синхронизируются в мультиплеере. Другие игроки видят ваши изменения, а вы видите их изменения.
